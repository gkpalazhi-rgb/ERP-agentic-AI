🧠 Intent Classification Pipeline
Three-layer cascade — keyword rules fire first, then BERT embeddings, then LLM as last resort.
flowchart TD IN([User Message]) --> NORM[Normalise text\nlowercase, strip punct] NORM --> CLR{Clarification\nResume Check} CLR -- Yes --> MERGE[Merge original query\n+ new answer\nclassify merged text] MERGE --> DONE CLR -- No --> KW[Layer 1 — Keyword Rules\nREGEX patterns per intent\nconst KEYWORD_INTENT_RULES] KW --> KW_HIT{Match?} KW_HIT -- Yes, conf ≥ 0.93 --> DONE KW_HIT -- No --> SEM[Layer 2 — Sentence-BERT\nall-MiniLM-L6-v2\ncached at startup] SEM --> EMB[Encode query\nto 384-dim vector] EMB --> COS[Cosine similarity\nvs. intent example matrix] COS --> THRESH{Best score\n≥ 0.65?} THRESH -- Yes --> DONE THRESH -- No --> LLM[Layer 3 — Ollama LLM\nllama3.2:3b\nJSON structured output] LLM --> LLM_OK{Valid plan\nreturned?} LLM_OK -- Yes --> DONE LLM_OK -- No, retry --> LLM2[Short prompt retry\nnum_ctx 512] LLM2 --> LLM2_OK{Valid?} LLM2_OK -- Yes --> DONE LLM2_OK -- No --> FB[Rule-Based\nFallback Planner\nagent.py] FB --> DONE DONE([Resolved Intent + Plan]) subgraph Intents [Supported Intents] I1[check_inventory] I2[create_purchase_order] I3[get_po_status] I4[generate_invoice] I5[get_vendors] I6[add_vendor] I7[update_vendor] I8[apply_leave] I9[stock_arrival] end DONE --> Intents style IN fill:#6366f1,color:#fff,stroke:none style DONE fill:#10b981,color:#fff,stroke:none style LLM fill:#f97316,color:#fff,stroke:none style LLM2 fill:#f97316,color:#fff,stroke:none style FB fill:#f59e0b,color:#fff,stroke:none
